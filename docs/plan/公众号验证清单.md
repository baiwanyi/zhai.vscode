# 公众号模块验证清单

> 用途：按顺序验证已落地的真实接口。**所有 `api.weixin.qq.com` 调用至今没有过一次真实往返**，
> 报文形状都按官方文档对齐，因此这一步的目标不是「跑通功能」而是「找出文档与现实的偏差」。
> 每一步都给了「操作 / 预期 / 失败怎么查」，最后有一张记录表，把报错原文填进去即可。
>
> 关联文档：`docs/modules/wechat.md`（第 15 节是剩余待办与已知约束）。

## 1. 账号（M1）

### 1.1 添加账号（故意不配白名单）

- **操作**：侧栏打开「宅写作」仪表盘 → 概览页点「公众号管理」→ 底部 `+` → 填名称、类型、AppID、AppSecret → 提交
- **预期**：提交失败，提示「调用方 IP 不在公众号后台的 IP 白名单内：请把当前出口 IP 加入…」；账号已入列表且状态为「错误」（红色色点）
- **失败怎么查**：
  - 提示是英文 errmsg → 错误码表漏了，把 errcode 记下来
  - 账号没入列表 → 创建逻辑的「失败不回滚」没生效
  - 状态没变红 → `status_hint` 没落库

### 1.2 配置白名单后重新鉴权

- **操作**：把 1.1 里提到的当前出口 IP 加入后台白名单 → 列表行内 `...` → 重新鉴权
- **预期**：状态变「已连接」（绿色），提示成功
- **失败怎么查**：仍报 40164 → 出口 IP 与提示里的不一致（代理/VPN）

### 1.3 状态持久化

- **操作**：关闭并重开面板
- **预期**：状态与提示保持，不需要重新鉴权
- 这一条验证 `status_hint` 列的意义：重启后仍能展示上次的原因

## 2. 批次与文章（M2）

### 2.1 新建批次

- **操作**：点进账号 → 底部 `+` → 填标题（或留空）→ 创建
- **预期**：留空时自动命名「未命名批次 · 月-日」；卡片出现，状态「草稿」

### 2.2 手写文章（含本地图片与封面）

- **操作**：批次菜单 → 添加文章 → 填标题、作者、摘要 → 正文用 Markdown 写，**插入一张本地 jpg/png**（`![图](../../images/xxx.png)` 这类相对路径）→ 封面选另一张图 → 勾选「允许读者留言」→ 保存
- **预期**：文章行出现，显示来源「手写」与字数；点开可再次编辑
- **失败怎么查**：保存报「正文超出 2 万字」→ 平台上限校验生效，属正常；图片路径错 → 生成草稿那步会给具体原因

### 2.3 从笔记导入

- **操作**：批次菜单 → 从笔记导入 → 选一篇 `notes/` 下的文档
- **预期**：选择器默认落在笔记目录；导入后标题取自 frontmatter 或首行，字数为正
- **失败怎么查**：选择器能选到 `press/` → 目录过滤没生效

### 2.4 从作品导入

- **操作**：同上，选 `press/` 下的章节文档
- **预期**：来源显示「作品」

### 2.5 编辑 / 移出 / 合并 / 批量删除

- **操作**：文章行 `...` → 移出；勾选两个草稿批次 → 「合并到…」；再勾选 → 「删除所选」
- **预期**：合并后目标批次篇数相加、源批次消失；**合并后超过 8 篇时提交按钮禁用并说明**；已推送批次无法被勾选

## 3. 渲染与草稿（M3a / M3b）★ 最关键

这一步能暴露渲染管线与素材上传的绝大部分问题。

### 3.1 生成草稿

- **操作**：批次菜单 → 生成草稿
- **预期**：页面顶部出现阶段提示（渲染第 N/M 篇 → 上传图片素材 → 提交草稿）；成功后状态变「草稿已就绪」；若正文有外链图片会出现一条 warning
- **失败怎么查**：
  - 「缺少封面」→ 指定封面与正文首图都没有，属预期拦截
  - 「仅支持 jpg/png」→ 图片格式不在白名单
  - 45166 → 正文未通过平台校验（通常是敏感词或外部链接）

### 3.2 到后台草稿箱逐项核对 ★

- **操作**：批次菜单 → 打开公众号后台 → 草稿箱 → 打开刚生成的草稿
- **逐项检查**：
  - [ ] 标题、作者、摘要正确
  - [ ] 正文字号约 15px、行高约 1.8（主题是否内联成功）
  - [ ] 标题分级有层次（h2 左侧色条）
  - [ ] 引用块有浅灰底、表格有边框
  - [ ] 代码块有底色与等宽字体，内容完整（当前不做语法高亮）
  - [ ] **图片全部能显示**（这是素材上传是否成功的直接证据）
  - [ ] 封面是第 2.2 步里指定的那张
  - [ ] 留言开关为开启（若账号已开通留言）
- **失败怎么查**：
  - 字号/行高全丢 → `theme.ts` 的根选择器与 juice 内联有问题
  - 图片裂开 → 素材上传失败或 URL 未替换，回到 3.1 看 warning
  - 样式部分丢失 → 平台过滤了某些标签/属性，记录具体是哪一项

### 3.3 更新草稿（幂等）

- **操作**：回到批次菜单 → 「更新草稿」
- **预期**：后台**仍然只有一份**草稿（走 `draft/update` 而不是新增）
- **已知缺口**：内容没改也会重写一次（见第 15.2 节「草稿幂等」）

## 4. 群发（M3c）

> 未认证主体请在 4.1 后直接跳到 4.4 的结果确认。

### 4.1 打开确认弹窗

- **操作**：批次菜单 → 群发
- **预期**：弹窗展示账号名、文章清单、**额度说明**（订阅号「今日尚未群发」/ 服务号「本月剩余 N 次」）、不可撤销提醒

### 4.2 确认群发

- **操作**：点确认
- **预期**：顶部阶段提示走到「提交群发任务」→「等待平台发布结果」；10 秒内状态变「已推送」，卡片可「打开公众号后台」
- **失败怎么查**：
  - `48001` → 未认证主体，提示应引导「去后台手动群发」而不是报错
  - `45009` → 额度已用尽，提示应给出恢复时间
  - 一直停在「推送中」→ `freepublish/get` 未返回终态，属设计内（不臆断），但需要记录实际返回

### 4.3 额度拦截

- **操作**：同一天再发第二个批次（订阅号）
- **预期**：确认弹窗里就显示「今日额度已用完，明天 0 点后恢复」，点确认被拦

### 4.4 未认证主体的表现

- **预期**：提示「该账号没有发布权限，通常是未认证主体：草稿已在后台，请到公众号后台手动群发」；批次变「推送失败」但草稿仍在后台

## 5. 工作流六分区（M4）

### 5.1 六个入口是否出现 ★

- **操作**：从仪表盘 `#/wechat` 点进某个账号页 → 侧栏切到工作流面板
- **预期**：侧栏出现 菜单 / 素材 / 统计 / 留言 / 用户 / 推送 六个入口（面板高度不够时可滚动）
- **失败怎么查**：入口没出现 → `selectedModule` 没被设置；这是 M4 的 P0 修复点，回归时优先看它

### 5.2 自定义菜单

- **操作**：进入「自定义菜单」→ 若有线上菜单应能读出 → 改一个名字 → 发布
- **预期**：发布后回读的菜单与修改一致；到公众号后台「自定义菜单」确认已生效
- **失败怎么查**：名称超 16 字节会被拦（约 5 个汉字以上），这是平台限制

### 5.3 素材管理

- **操作**：看列表（应有 3.1 自动上传的图）→ 用文件名搜索 → 上传一张新图 → 删除它
- **预期**：搜索为本地过滤；删除后到后台「素材管理」确认平台侧也没了
- **注意**：删除已发布文章引用的图会让正文图片失效，界面已写进确认文案

### 5.4 用户管理

- **操作**：看粉丝列表（昵称、头像、关注时间）→ 切到标签
- **预期**：粉丝显示前 100 位并在标题旁标明总数；标签只读
- **已知约束**：不做翻页，因为平台资料接口一次只收 100 个 openid

### 5.5 数据统计

- **操作**：切换 7 / 15 / 30 天
- **预期**：认证账号出指标卡与逐日柱状；未认证应显示平台返回的权限提示（不是空图表）

### 5.6 留言管理

- **操作**：选批次 → 选文章 → 看留言列表
- **预期**：有留言则显示「读者 …尾号 + 相对时间 + 内容」；可回复、设为精选、删除
- **失败怎么查**：
  - 「该批次没有群发消息标识」→ 这是升级前群发的批次，需重新群发一次
  - `48001` → 未认证或未开通留言

### 5.7 推送管理

- **操作**：看三段（待推送 / 历史 / 额度）
- **预期**：进行中的推送在顶部有「进行中任务」条；历史里失败批次显示失败原因

## 6. 异常与边界

### 6.1 断网时生成草稿

- **操作**：断开网络 → 生成草稿
- **预期**：报网络错误；**账号状态不应被改成「错误」**
- 这条验证 `tokenService` 只对平台错误码上报、不发网络失败

### 6.2 故意改错 AppSecret

- **操作**：账号设置 → 把 AppSecret 改成一个错误值 → 保存（保存会触发鉴权）
- **预期**：本地提示鉴权失败；若此时停在账号列表，还应收到一条 toast「「账号名」鉴权失效：…」
- 若要在别处触发：改错密钥后去工作流传一张素材图，回到列表应能看到状态已变红

### 6.3 删除账号

- **操作**：删除账号
- **预期**：回到列表；工作流六分区回到空态并提示「先到仪表盘添加账号」；`AppSecret` 从密钥存储中清除

## 8. 发现问题的处理方式

把记录表里的「报错原文」连同以下三项一起给出，可以直接定位：

1. 出错的是哪个步骤（如 3.2）
2. 平台返回的完整报文（`errcode` + `errmsg`，若是渲染问题则贴后台截图）
3. 是否能稳定复现

错误码多半落在三个表里，改文案或补码就在对应文件：

| 场景 | 文件 | 说明 |
|------|------|------|
| 鉴权（Token 换取） | `src/modules/wechat/client.ts` | `ERROR_HINTS` |
| 素材上传 / 删除 | `src/modules/wechat/client.ts` · `openapi.ts` | `MATERIAL_ERROR_HINTS` |
| 草稿提交 | `src/modules/wechat/client.ts` | `DRAFT_ERROR_HINTS` |
| 发布 / 群发 | `src/modules/wechat/client.ts` | `PUBLISH_ERROR_HINTS` |
| 运营接口（菜单 / 粉丝 / 统计 / 留言） | `src/modules/wechat/openapi.ts` | 走通用 `describeWechatError`，未登记的码会落到兜底文案 |
