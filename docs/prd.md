# 宅桌面 (Zhai Desktop) - 产品需求文档 (PRD)

**版本**：2.0
**日期**：2026-05-30
**状态**：已发布

---

## 1. 产品概述

### 1.1 产品定位

宅桌面是一款**一站式桌面应用管理平台**，基于 Node.js 的全栈浏览器桌面应用。它集成了媒体管理、笔记记录、AI 辅助写作、阅读工具和智能搜索等功能，为用户提供统一的本地化数字工作空间。

### 1.2 核心价值

- **本地优先**：所有数据存储于本地 SQLite 数据库，用户完全控制数据
- **AI 深度融合**：集成 DeepSeek API，提供流式对话、智能写作、图像翻译等能力
- **全栈一体化**：React + Express 全栈架构，开箱即用
- **原生体验**：在浏览器中享受桌面应用的流畅操作
- **响应式设计**：完美适配不同屏幕尺寸

### 1.3 技术架构

| 层级       | 技术选型                                  |
|------------|-------------------------------------------|
| 后端运行时 | Node.js + Express 5                       |
| 前端框架   | React 19 + TypeScript                     |
| 构建工具   | Vite 8                                    |
| UI 组件    | Tailwind CSS 4 + shadcn/ui + Tabler Icons |
| 数据库     | SQLite (通过 Drizzle ORM 管理)            |
| AI 集成    | DeepSeek API (SSE 流式)                   |
| 媒体处理   | ffmpeg + Sharp + Python 脚本 (Pillow)     |
| 外部服务   | Unsplash API (图片搜索)                   |

### 1.4 数据库架构

项目使用多个 SQLite 数据库文件：

| 数据库文件         | 用途               | 主要表                                                                                                                       |
|--------------------|--------------------|------------------------------------------------------------------------------------------------------------------------------|
| `data/zhai.db`     | 应用配置与 AI 日志 | `ai_usage_logs`, `options`, `conversations`, `responses`, `messages`                                                         |
| `data/notebook.db` | 笔记与 AI 对话     | `notebooks`, `notes`, `tags`, `note_tags`, `attachments`, `messages`, `message_fragments`, `note_revisions`, `chat_messages` |
| `data/gallery.db`  | 媒体文件管理       | `media`, `favorites`, `shorts`                                                                                               |
| `data/reader.db`   | 阅读模块           | `books`                                                                                                                      |

#### 3.1.3 网址快捷方式网格 — 核心设计

对标 Infinity New Tab Pro 功能，磁贴卡片 `112×96px`，支持：

| 功能 | 实现 |
|------|------|
| 自动 Favicon | `https://www.google.com/s2/favicons?domain=` |

| 数据持久化 | localStorage 存储，可选后端同步 |

**核心类型**：
```typescript
interface ShortcutItem {
    id: string            // UUID
    name: string          // 显示名称
    url: string           // 完整 URL（含协议）
    iconType: 'favicon' | 'emoji' | 'tabler' | 'color'
    iconValue: string     // 图标值
    order: number         // 排序序号
    bgColor?: string      // 自定义背景色
    createdAt: string
}
```

#### 3.1.4 后端 API

```typescript
// GET /api/dashboard/stats — 聚合统计数据
interface DashboardStats {

| 方法 | 路径 | 说明 |

| GET | `/api/dashboard/stats` | 聚合所有模块统计数据 |
| GET | `/api/dashboard/activity` | 跨模块最近活动（可选） |

**数据流**：`useDashboardStats()` Hook → `GET /api/dashboard/stats` → Controller → Service（4 数据库查询）→ 聚合 JSON 返回。

### 3.2 笔记管理 (Notebook)

**路由**：`/notebook/:postId`

**需求描述**：支持 Markdown 和 DeepSeek 格式笔记的创建、编辑、组织和搜索，集成 AI 对话能力。

#### 3.2.1 笔记管理

| 功能点            | 描述                                                               | 优先级 |
|-------------------|--------------------------------------------------------------------|--------|

| Markdown 编辑     | 基于 `@mdxeditor/editor` 提供所见即所得编辑体验                    | P0     |
| 笔记本组织        | 支持嵌套笔记本 (notebooks) 树形结构组织笔记                        | P0     |
| 标签系统          | 支持为笔记添加标签，按标签筛选和搜索                               | P1     |
| 版本历史          | 自动保存修订版 (noteRevisions)，支持恢复历史版本                   | P1     |
| 笔记搜索          | 按标题模糊匹配搜索笔记                                             | P1     |
| 图片粘贴/拖拽上传 | 支持从剪贴板粘贴截图、从桌面拖拽图片到编辑器，自动上传为附件       | P1     |
| 笔记模板系统      | 预设笔记模板（会议记录、读书笔记、周报等），支持用户自定义保存模板 | P1     |
| 数据库定期备份    | 自动定时备份 notebook.db 至备份目录，保留最近 N 个备份版本         | P1     |

**用户场景**：
1. 用户创建笔记本（如"技术笔记"、"读书笔记"），在其中新建 Markdown 笔记
2. 用户编辑笔记内容，系统自动保存并记录修订版
3. 用户为笔记添加标签，方便分类检索
4. 用户使用搜索功能快速定位笔记
5. 用户通过版本历史查看变更并恢复到任意历史版本
6. 用户从剪贴板粘贴截图或从桌面拖拽图片，系统自动上传并插入编辑器
7. 用户从模板库中选择预设模板快速创建笔记
8. 系统每日自动备份数据库，用户可随时从备份恢复

**验收标准**：
- 编辑器支持标准 Markdown 语法（标题、加粗、斜体、列表、引用、代码块、链接、图片）
- 自动保存触发频率 ≤ 5 秒防抖
- 修订版保留至少 30 个历史版本
- 搜索响应时间 < 200ms
- 图片粘贴/拖拽上传处理时间 < 3 秒（含缩略图生成）
- 数据库备份自动执行，不影响前台操作

└── index.tsx               # 前端占位入口
```

**数据流**：
```
用户 POST /api/reader/scan → controller → service.scanAndImport(txtDir)
  → walkDirectory()       递归扫描 .txt 文件
  → computeMD5()           流式计算 MD5
  → isAlreadyImported()    比对去重
  → detectAndRead()        jschardet 检测编码 + iconv-lite 解码
  → importSingleFile()     INSERT INTO books
  → 返回 { totalFiles, newFiles, skippedFiles, errors }
```

#### 3.5.4 API 接口

| 方法 | 路径 | 功能 | 状态 |
|------|------|------|------|
| POST | `/api/reader/scan` | 手动触发扫描目录 | 已完成 |
| GET | `/api/reader/list?page=1&pageSize=50` | 获取未删除书籍列表（按最后阅读时间倒序，分页） | 已完成 |
| GET | `/api/reader/:bookId` | 获取单本书详情 | 已完成 |
| DELETE | `/api/reader/:bookId` | 软删除书籍 | 已完成 |

**扫描响应示例**：
```json
{ "success": true, "data": { "totalFiles": 12, "newFiles": 5, "skippedFiles": 7, "errors": [] } }
```

#### 3.5.5 依赖

| 包 | 用途 |
|----|------|
| `jschardet` | 编码检测 |
| `iconv-lite` | 编码转换为 UTF-8 |

#### 3.5.6 验收标准

| 场景 | 预期 |
|------|------|
| 配置 txtDir，目录有 5 个 `.txt` | 扫描后导入 5 本 |
| 再次扫描（文件未变） | 全部跳过，`newFiles: 0` |
| 目录新增 2 个 `.txt` | 导入 2 本新书，跳过 5 本旧书 |
| 包含非 `.txt` 文件（.pdf） | 自动忽略 |
| GBK 编码文件 | 正确检测为 GBK，正常存储 |
| 大文件 >100MB | 流式计算 MD5，不阻塞 |
| 目录不存在 | 输出警告，不崩溃 |
| 文件相同但文件名不同 | MD5 相同，去重跳过 |

| 状态码 | 使用场景                   |

| API Key 未配置      | 返回 401，提示"请先在设置中配置 AI API Key"                      |
| Token 配额超限      | 返回 429，提示"请求频率超限，请稍后重试"                         |
| 文件导入格式错误    | 返回 400，提示"文件格式不正确，请上传 DeepSeek 导出的 JSON 文件" |
| 媒体文件不存在      | 返回 404，自动清理数据库中的无效记录                             |
| 数据库操作失败      | 返回 500，记录错误日志                                           |
| 脚本执行异常        | 通过 SSE 输出 error 事件，包含错误信息                           |

### 5.4 服务器异常保护

- 请求体大小限制：JSON 1MB，URL 编码 1MB
- 静态文件目录安全校验：防止路径穿越攻击
- 安全头：通过 helmet 中间件配置 CSP、XSS 保护
- 响应压缩：通过 compression 中间件提升性能
- 端口冲突：自动检测并提示友好错误信息
- 优雅关闭：收到 SIGTERM/SIGINT 后等待现有连接完毕
- 未捕获异常：记录日志后安全退出，避免进程处于未知状态

### 7.4 UI/UX 优化

- **全局搜索栏**：在顶部导航栏添加全局搜索入口，一次搜索同时匹配笔记标题/内容、媒体文件名/标签、作品章节
- **键盘快捷键体系**：建立统一的快捷键映射表（Ctrl+K 搜索、Ctrl+N 新建笔记、Ctrl+Shift+F 切换图库视图等），各模块内保持一致
- **深色模式增强**：确保所有组件在深色模式下均无样式断裂，覆盖全部自定义组件
- **拖拽交互**：笔记间排序、标签归类、图库多选等场景支持拖拽操作
- **骨架屏/加载态**：列表和详情页面在数据加载时显示骨架屏而非空白或闪烁
- **空状态设计**：模块无数据时展示引导性空状态，提示用户如何开始使用
- **操作反馈**：关键操作（删除、收藏、保存）以 Toast 通知反馈结果，提供"撤销"按钮（3 秒内可撤销）
- **响应式三栏布局**：窄屏下自动折叠侧边栏为抽屉式，确保平板/手机浏览器可用

### 7.5 响应速度优化

- **数据库连接池**：后端使用单例 SQLite 连接池，配合 WAL 模式提升并发读写性能
- **前端数据缓存**：对不频繁变动的数据（笔记本列表、标签列表、统计概览）使用 React Query 的 staleTime 缓存，减少重复请求
- **图片懒加载**：瀑布流列表使用 Intersection Observer 实现图片懒加载，进入视口前不发起请求
- **大笔记加载优化**：10 万字以上笔记的编辑性能优化，利用编辑器增量渲染或分段加载机制
- **API 批量操作**：批量删除、打标等操作使用单次 API 请求处理，避免逐个请求导致 N+1 问题
- **缩略图多级缓存**：三级缩略图（200px/400px/800px）按需使用，瀑布流列表加载小尺寸，查看器加载大尺寸
- **响应压缩**：API 响应启用 gzip/brotli 压缩，减少网络传输体积

### 7.6 数据安全增强

- **自动备份策略**：每日首次启动自动备份所有 SQLite 数据库文件至 data/backup 目录，保留最近 7 天备份，支持用户手动触发即时备份
- **加密笔记**：支持对单篇笔记或整个笔记本进行 AES-256-GCM 加密，查看时需输入密码解密（可选功能）
- **回收站自动清理**：笔记回收站增加保留天数配置（默认 30 天），超期自动物理删除；提供"清空回收站"一键操作
- **操作确认与撤销**：删除笔记/图库前显示确认对话框，并提供 3 秒内可撤销的 Toast 通知
- **附件存储完整性校验**：文件化存储后，定期校验附件文件的 MD5 哈希与数据库记录的一致性，发现损坏自动告警
- **数据库 WAL 模式**：启用 SQLite WAL（Write-Ahead Logging）模式，提升写入性能并降低数据库损坏风险
