## AI 对话底部输入区改造：命令 / 参考 / 模式切换 / Token 圆环 / 增强 / 写回编辑栏

### 变更

- 输入区改为三段式卡片（`InputGroup` + `block-start` / `block-end` 两个 addon）：顶部工具行仅「命令」「参考」两个按钮，中间多行输入框，底部左侧模式按钮 + 右侧三按钮。
- 命令菜单四项：改写 / 润色 / 找错别字 / 去 AI 味，点击把指令模板填入输入框（已有内容时追加一行）；命令带 `applyPolicy`，找错别字为 `report` 不提供写回。
- 参考菜单四项（古诗词 / 名言名句 / 经典文本 / 历史资料）为占位，点击仅提示「即将上线」，不发起请求；清单由 `AI_REFERENCE_SOURCES` 驱动，置 `enabled` 即可接入。
- 底部新增模式切换（对话 / 写作），经 `ai/setMode` 写入 `conversations.mode` 持久化，生成中禁用。
- 右下三个按钮：Token 圆环（SVG 自绘，<70% 主色 / 70~90% 警示 / ≥90% destructive，Popover 显示已用 / 预算 / 剩余）、增强提示词（本地规则化补齐任务与要求，二次点击还原）、发送 / 停止。
- 增强提示词的规则化纯函数放入既有 `aichat/utils.ts`，不新增工具文件；`readAiStateKind` 增加 `writeTarget`。
- 移除输入区齿轮按钮，设置入口迁移到 `zhai.workflow` 视图标题栏（`menus.view/title` + `zhai.openSettings` 的 `$(gear)` 图标）。
- 写作模式写回：`ai/writeState` 下发实时目标、每条可写回消息的作用域与已写回集合；`ai/applyWrite` 只接受消息 id，宿主用发送时快照的 uri / `document.version` / range 校验后 `WorkspaceEdit.replace` 写入，进入撤销栈；整篇覆盖前界面二次确认。
- 写作目标捕获：选区优先，无选区取整篇，整篇上限 12000 字符；原文以 `<context>` 注入，与待发送引用同范围时去重，不重复灌入。
- 写回快照按助手消息 id 隔离（不同轮次互不覆盖），可写回与已写回集合按会话隔离，删除会话时一并清理。
- 消息区新增「应用到编辑栏」按钮，并把 `AiChatMessageView` 内联的引用条目、正文、写回按钮拆为独立文件；业务组件一律一文件一组件。
- 生成结束后前端刷新运行时用量与写回状态，宿主在模式切换、生成完成、写回成功、删除当前会话时广播 `kind: writeTarget`。
- `AiChatStatusHint` 增加模式提示层级，并修正原「Ctrl+Shift+L 聚焦123」文案。

### 依据

- 用户确认：设置入口移到侧栏顶部（A）、本期不做 `/` 交互（B）、本期必须可写回编辑栏（C）。
- 整篇改写设上限：超出时模型只看到截断内容却覆盖全文会丢内容，故强制分段选中。
- 写回不传 uri / 行号，避免 Webview 越权写入任意文件位置；文档版本不一致即拒绝，不做自动合并。
- 本期为「整段替换 + Ctrl+Z 撤销」，与设计文档 A3 的 diff 逐段接受分开记录。

## AI 对话输入卡片视觉对齐 CodeBuddy 模板

### 变更

- 输入区由 `InputGroup` + 三段 addon 改为单层圆角卡片：容器 `rounded-2xl bg-input-background p-1.5`，工具行与操作行改为普通 flex 行，不再依赖 addon 的 order/对齐规则。
- 去掉焦点边框与聚焦光晕：输入框改用 `Textarea`，覆盖 `border-0 bg-transparent shadow-none focus-visible:border-transparent focus-visible:ring-0`，彻底摆脱 InputGroup 的 `has-[[data-slot=input-group-control]:focus-visible]` 规则。
- 工具行与操作行按钮由 `InputGroupButton` 改为 `Button`：图标按钮用 `icon-sm` + ghost 圆形弱化色，模式按钮改为 secondary 圆角 pill（对齐模板的 Craft 按钮）。
- 发送按钮两态：未输入与增强按钮同底色（`bg-white/5` + `text-muted-foreground`，并覆盖 disabled 透明度），输入后可点为主题主色（`bg-primary` / `text-primary-foreground`），统一 `rounded-lg` 方块；增强与停止按钮同样为 `rounded-lg` + `bg-white/5`。
- 修复输入框首帧闪色：`Textarea` 基础类的 `disabled:bg-input/50`、`dark:disabled:bg-input/80` 与 `transition-colors` 会在 runtime 未就绪（`hasApiKey` 暂为 false）时先渲染禁用底色再淡出；输入框改为覆盖 `disabled:bg-transparent`、`dark:disabled:bg-transparent`、`disabled:opacity-100` 与 `transition-none`。
- 同源提示闪烁一并消除：输入卡片新增 `isRuntimeReady`，运行时未加载时保持中性占位「提问或输入指令…」且不按 Key 禁用，确认无 Key 后才显示设置提示并禁用。
- 发送图标由 `SendHorizontal`（旋转 -90°）改为 `Send` 纸飞机，更贴近模板。
- 未引入截图中的模型选择与 Skills 按钮（沿用既有的「移除模型 / 技能选择」需求）。
- 输入区增加独立底色：外层卡片使用新增令牌 `bg-composer`，内层以 `rounded-xl bg-input-background` 包裹 Textarea，形成与卡片底色可区分的输入块。
- 新增输入卡片两层令牌：`--composer-background: #2c2c2d` 与 `--composer-input-background: #3c3c3c`，并在 `@theme inline` 注册 `--color-composer` / `--color-composer-input`（`bg-composer` / `bg-composer-input`）。原因：`#2c2c2d` 与 VSCode Dark Modern 的 `input.background`（#313131）仅差 5，沿用 `bg-input-background` 时内外层几乎同色；改为固定明度差 16 的两层（输入区更亮），亮色主题用 `body.vscode-light` 覆盖为浅色两层。
