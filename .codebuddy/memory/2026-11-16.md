## 「添加上下文」菜单闪退修复

**现象**：点击工具行左侧「添加上下文」后菜单闪退（弹出即消失）。

**原因判断**：`DropdownMenu` 与 `Popover` 两层浮层在同一事件里一关一开——菜单项 `onSelect` 直接 `setIsPickerOpen(true)`，Radix 会把新面板判为「外部交互」立即收起；同时菜单默认 `modal=true` 会给页面加 `aria-hidden` 与指针事件限制，与 Popover 叠加时加重冲突。

**修复**：① 菜单项点击只关闭菜单，`requestAnimationFrame` 后再打开面板，让菜单先完成卸载与焦点归还；② 上下文菜单加 `modal={false}`，工具行菜单不锁页面滚动，避免两层弹层互相关闭；③ Popover 的 `onOpenChange` 统一走 `closePicker`，避免受控状态与 Radix 内部状态分叉。

**验证**：`tsc --noEmit` 通过；eslint 0 problems；全量测试 97 passed / 2 failed（既有 3 个用例未变）。是否真正消除闪退需在扩展宿主里手工点开菜单确认。

**闪退根治（改为单层浮层）**：上一步的「延后一帧打开」不足——点一级菜单项后 Popover 仍会立刻收起。根因是 DropdownMenu 与 Popover 两层浮层切换，Radix 把新开的面板判为外部交互。现改为**单层 Popover**：`PopoverTrigger` 直接是「添加上下文」按钮，Popover 内容按视图切换，一级列表（选择笔记本 / 笔记 / 文章 / 作品 / 规则）与二级内容同层渲染，任何点击都不关闭浮层。
