## 合并「清空索引」到「重建索引」

判定依据两条：一是 `fullRebuild()` 本身已等价于清空重建（FTS 由触发器随 files 同步，重建走 upsert + `pruneMissing` 清理孤儿记录，且取消/异常时不删记录，比先清空更安全）；二是既有 `clearSchemaData` 执行 `DELETE FROM meta`，而 meta 是共用表（配额计数、作品封面 `cover:*`、schema_version 都在里面），清索引会连带抹掉这些非索引数据。

**命令层**：`zhai.clearIndex` 从 package.json 命令表、`view/title` 菜单、`WEBVIEW_ALLOWED_COMMANDS` 白名单三处移除；`registerCommands` 删掉该注册与 `clearSchemaData` import，`db` 参数随之去掉（唯一用途就是它），`extension.ts` 调用同步。

**协议与仓储**：`clearSchemaData` 函数删除；宿主 `index/rebuild` case 与 `HostMethodName` 中的同名成员一并移除（webview 侧上一轮已无调用方）。

**文档**：`docs/modules/common.md` 命令表合并该行并说明等价关系；`docs/modules/dashboard.md` 的 QuickActions 改为「侧栏标题栏 … 菜单」现状。

**验证**：`tsc --noEmit` 通过；8 个改动文件 eslint 0 problems（全仓 eslint 另有 6 条既有 import 顺序错误，均在未改动文件）；`pnpm test` 1051 passed、3 failed，与改动前完全一致。

**修改**：`package.json`、`src/modules/common/commands.ts`、`src/modules/common/webviewCommands.ts`、`src/modules/common/db/schema.ts`、`src/modules/common/dashboardProvider.ts`、`src/shared/types/messages.ts`、`src/extension.ts`、`src/dashboard/hooks/useDashboardActions.ts`、`docs/modules/common.md`、`docs/modules/dashboard.md`
