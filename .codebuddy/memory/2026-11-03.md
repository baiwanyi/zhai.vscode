## 重构：生图并入媒体，升级为统一媒体管理模块（上传 / 筛选 / 关联归属）

- 存储模型：出图参数移出索引库——每图参数落 `images/{YYYYMM}/settings.json`（键为媒体 id，存 prompt / ratio / style / enhancedFrom，写的是最终提示词），全局出图配置落 `{存储根}/imagegen.json`；`media` 表升 v2（origin 收敛为 generate / upload、新增 origin 索引），旧参数列由服务层导出到磁盘后 `DROP COLUMN`，此后只认 json；不做旧作品 `.zhai/image.json` 的继承。
- 命名：随机段字母表改为 `[A-Z0-9]`，文件名形态为 `YYYYMMDDHHmmss` + 6 位；`isMediaId` 读侧仍允许小写，历史文件不受影响。
- 统一入口：`workflow/imagegen` 整体并入 `workflow/media`，`WorkflowImagegen` 收敛为 `WorkflowMedia`（`context: MediaContext | null`）；作品分区与常驻分区渲染同一页，非作品上下文也能出图（`scope=general`、kind 限 photo，角色图与条目图需要作品归属）。
- 上传：新增 `media/pickUpload`（宿主弹选择器、零拷贝）与 `media/uploadBytes`（拖拽 / 粘贴走 base64），统一 `origin=upload`、`scope=general`、`kind=photo`；校验为魔数嗅探 + 单张 10MB + 单批 20 张 + 总量 40MB；前端 `useMediaUpload` 提供三通道回执与拖拽高亮。
- 筛选与关联：`useImageFilters` 扩为「年月 / 来源 / 关联」三维（关联判定 `usageCount > 0`），筛选签名三段并驱动分批复位；新增 `mediaOwners` 把引用折算成「作品名 / 具体笔记 / 公众号批次 / 外部文档」，详情面板按归属分组。
- 关联有效性：`media/rescan` 增加 `force` 参数与 `media_meta.last_full_scan_at` 跨会话节流（5 分钟），页面挂载后台扫描一次并提供「重新扫描关联」按钮——此前 `media/rescan` 没有任何前端调用点，`usageCount` 恒为 0。
- 文案：卡片「未关联」改「无出处」、「被 N 处使用」改「关联 N」，「关联」一词专指引用关系。
