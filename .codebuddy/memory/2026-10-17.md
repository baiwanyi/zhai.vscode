# 2026-10-17

## 仪表盘内新增写作管理页（#/press）：作品列表与添加作品

### 变更

- 仪表盘 Webview 引入页内路由：hash 承载路径（`#/` 概览、`#/press` 写作管理），未登记路径回落概览；`dashboardScreen.tsx` 成为唯一页面切换点，入口 `main.tsx` 改挂该外壳。
- 「写作管理」入口由「跳转工作流面板」改为页内导航；「公众号管理」保持原有工作流跳转。工作流 press 页与 `AiChatViewProvider` 未改动。
- 新增 `/press` 页面：返回按钮 + 全宽「添加作品」+ 作品列表（作品名、章节数、字数、最近时间），空态提供「添加作品」「重建索引」，加载态骨架、失败态重试。
- 新增作品契约 `shared/types/press.ts`：作品摘要、创建/打开请求与收窄函数、分类枚举（玄幻/都市/历史/科幻/悬疑/言情/其他，默认「其他」），前端选项与落盘 Frontmatter 共用一份。
- 新增 `modules/press`：`projectRepository`（索引库前缀聚合作品摘要、按目录回查存在性）、`projectFactory`（作品名白名单校验、骨架模板）、`projectService`（骨架落盘 + 逐文档索引、按目录打开 README）。
- 仪表盘宿主新增 `press/projects`、`press/create`、`press/open` 三个协议；创建成功后自动打开 README，分类非法值回落默认值。
- 从 `noteService` 提炼 `modules/common/storagePath.ts`（存储 Uri 构造、片段校验、相对路径归一化、存在性判定），笔记与作品共用，错误文案按调用方传入的实体名区分。
- 测试桩 `workspace.fs.stat` 增加目录语义（FileType.Directory = 2），使「目标目录已存在」可被单测覆盖。

### 依据

- 目录即作品（`press.md` 1.2）：作品元信息与结构都在 Markdown 与目录上，索引库仅缓存，故本期不引入 `press.db`，避免出现第二套事实源与对账逻辑。
- 索引扫描用 `substr(path, 1, ?) = ?` 而非 `LIKE 'press/%'`：作品名可能含 `_` 与 `%`，LIKE 会误匹配且需额外转义。
- 表单重置改为页面端更换组件 `key`（重挂载回初始值），避免在 effect 中同步写 state（`@eslint-react/set-state-in-effect`）。
- 侧栏宽度有限，作品列表采用单列行式条目（复用 `Item` 语义），不做卡片网格。
