## 修复：光晕透进表单内容区（看起来像浮在表单前面）

- 原因：光晕的 `-z-10` 本就在输入组之下，但 InputGroup 背景是半透明的（`dark:bg-input/30`，浅色主题无底色），背光透过底色把正文染成紫粉色，观感等同「浮在前面」。
- 改法：在光晕与输入组之间插一层不透明底衬 `<div aria-hidden className="pointer-events-none absolute inset-0 rounded-lg bg-background" />`。底衬是定位元素，层级高于负 z-index 的光晕、低于同为定位元素的 InputGroup，只遮内容区；光晕的描边（-inset-px）与背光（-inset-2 + blur）在底衬范围外，仍然可见。
- 未采用方案：给包裹层加 `bg-background` 无效——形成层叠上下文的元素自身背景绘制在负 z-index 子层之下，遮不住光晕；给 InputGroup 加 `bg-background` 又会被 `dark:bg-input/30` 按 CSS 顺序抢走，不可控。
- 验证（逐项）：`pnpm run typecheck` exit 0；`eslint` 0 问题；`prettier --check` 通过；`pnpm run compile` 通过；底衬 5 处（设定页）+ 1 处（人物外貌）已核对齐全。
