## 追加：块把手定位、菜单对齐与表格插入修复

**把手压进正文**：原先按 `isEmptyLine` 条件卸载内容，DragHandle 会在元素宽度为 0 时算左侧坐标，按钮因此压住占位文本。改为内容常驻渲染、非空行只叠 `invisible`，定位宽度恒定。

**恢复整行拖拽**：把手重新拆成「拖拽手柄 + 加号按钮」两个元素，`GripVertical` 负责拖走整块，`CirclePlus` 只负责开菜单。

**菜单对齐 `/`**：菜单项改用 `SLASH_COMMANDS`（含表格、表情、分隔线、纯文本），并补 hint 文案；`TURN_INTO_COMMANDS` 与未再使用的 `TABLE_ACTIONS` 一并删除。命令执行前用 `setTextSelection(pos + 1)` 把光标移进当前空行，避免插入类命令落到旧光标所在的块。

**表格插入失败**：根因是块级回写的固定下标对齐——在末尾空行插入表格后前端多出块，`change.index` 越界，`buildBlockEdits` 直接 `continue`，宿主什么都没写，500ms 后被 baseline 刷新掩盖成"成功"。改为把越界块按 index 升序追加到全文末尾（空文档落在 0 偏移），并维护倒序排序；对应单测由「越界下标被忽略」改为「越界视为新增块追加到末尾」，另补「越界但内容为空不写入」。

## 追加：表格可见性、把手按内容分形态、回写改为偏移定位

**表格看不见**：`editor.css` 里原本没有任何表格规则，Tiptap 输出的 `table / colgroup` 在浏览器默认样式下几乎不可见，插进去等于没插。补了边框、单元格内边距、表头底色与 `selectedCell` 选中底色。

**把手分形态**：空行只出 `CirclePlus`（开菜单），有内容的行只出 `GripVertical`（拖拽整块）；容器固定 32px 槽位（`w-8`），避免两种形态宽度不同让 DragHandle 的左侧坐标跳动。

**回写定位根治**：块下标在插入/删除块后会整体位移，之前"越界追加"的补丁在中间插块时会写出重复内容（探针实测把 `123` 拆块后插表，旧逻辑生成 3 条 edit、正文出现重复段落）。改为：
1. 协议 `EditorBlockChange` 由 `{index, html}` 改为 `{start, end, htmls}`，`EditorChangeRequest.blocks` → `edits`；`EditorChangeResult` 回传写入后的 `blocks` 供前端刷新基准；
2. 新增 `src/editor/blocks/blockDiff.ts`：LCS 对齐内容未变的块，两处匹配之间的空档整体算一次替换（支持中间插入、末尾追加、删除、替换），纯插入锚点取前块 end / 首块 start / 0；
3. `useEditorDocument` 采集块时跳过空文本块（编辑器尾部恒有空段落），`flush` 改发区间变更；
4. `editorDocService.buildBlockEdits` → `buildEdits(text, ranges)`：校验范围与整数偏移、丢弃重叠区间、按偏移倒序、块间自动补空行分隔；转换失败（合并单元格表格）与"删除"分开处理，前者保留原文。
