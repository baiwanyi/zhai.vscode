## 调整：移除 Image 的 fill 参数

- 依据：className 里传 `size-*`（如 `size-3.5`）时，cn（tailwind-merge）会把 `size-full` 整组覆盖，无需再额外开一个开关
- `Image` 删除 `fill` 字段、解构与条件判断，`frameClass` 恢复为固定 `size-full`；头部注释改写为「`size-*` 覆盖规则 + 父容器高度由内容决定时改传 `w-full`、高度交给 aspect 解析」
- 调用点同步去掉 `fill={false}`：`CoverGallery`、`CharacterPortraitPanel`、`ModelIcon`
- 验证：全仓无 `fill` 残留；`eslint` 无诊断；`prettier --check` 通过；`pnpm run typecheck` exit 0
- 涉及文件：`Image.tsx`、`CoverGallery.tsx`、`CharacterPortraitPanel.tsx`、`ModelIcon.tsx`

## 调整：Image 的 size 默认值改为 none

- 默认不再自带圆角，圆角统一交给外层容器（卡片 `overflow-hidden` + `rounded-*`）决定，避免组件与外层各写一套
- 同步 `interface` 注释；现有调用点均显式传参（`PressProjectCard` = full、`CharacterList` = none、`CharacterPortraitPanel` = lg、`ModelIcon` = none），`CoverGallery` 不传即落到 none
- 验证：`eslint` 无诊断；`prettier --check` 通过；`pnpm run typecheck` exit 0
- 涉及文件：`src/webview/components/Image.tsx`

## 复查：Image 组件在各调用点的用法

- 修正 `ModelIcon`：厂商图标并非等比（deepseek 1391×1024、minimax 1169×1024），组件默认 `object-cover` 会把 14×14 容器两侧裁掉 → 补 `object-contain`
- 修正 `CharacterPortraitPanel`：`aspect="9/16"` 配合 `max-h-[72vh]` 时容器实际变成横向，默认 `object-cover` 会裁掉竖图上下大半 → 补 `object-contain`，保证预览完整（同时修正把 JSX 注释误放进三元分支导致的语法错误）
- 修正 `CharacterList`：`Image` 自带 `size-full`（宽度 100%），直接放在 `Card` 的 flex 行内会与文字区争空间 → 外层补 `w-12 shrink-0` 定宽，高度仍由 `aspect="3/4"` 决定
- 判定正确、未改动：`PressProjectCard`（`ItemMedia variant="image"` 已提供尺寸与 `[&_img]` 约束，`size="full"` 圆形封面正确）、`CoverGallery`（比例映射正确，宽度由三列网格决定）
- 遗留提示：`CoverGallery` 的 `size="sm"` 与外层卡片 `rounded-lg` 形成双圆角；`CharacterList` 改 `src={coverUrl || ''}` 后无封面显示通用图片占位，原 UserRound 人形占位语义丢失；`CoverGallery` 的 variant→比例映射有两份（Skeleton 用类名、Image 用三元）
- 验证：`eslint` 无诊断；`prettier --check` 通过；`pnpm run typecheck` exit 0
- 涉及文件：`ModelIcon.tsx`、`CharacterPortraitPanel.tsx`、`CharacterList.tsx`
