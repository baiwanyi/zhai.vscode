## 仪表盘作品详情章节标题单行截断

- 现象：章节标题过长时折成多行，`truncate` 不生效。根因是 `ItemContent`（`flex flex-1 flex-col`）缺 `min-w-0`，flex 子项默认 `min-width: auto` 无法收缩，内容宽度把整行撑开。
- 只补 `min-w-0` 后变成硬切、没有省略号：`ItemTitle` 基础类含 `flex`，`text-overflow: ellipsis` 在 flex 容器上对匿名文本项不生效。
- 最终写法（`PressVolumeSection.tsx` 章节行）：`ItemContent className="min-w-0"`、`ItemTitle className="line-clamp-none block w-full truncate text-xs"`、`ItemActions className="shrink-0"`。`line-clamp-none` 用于在 twMerge 中顶掉基础类的 `line-clamp-1`，同时 `block` 顶掉 `flex`；产物 CSS 中 `.truncate`（overflow/text-overflow/nowrap）排在 `.line-clamp-none` 之后，故块级 + 省略号成立。

## 修复：点导入按钮报「文件系统提供程序不可用」
