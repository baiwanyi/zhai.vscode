## 修复：人物标识非法，无法定位角色卡目录

- 根因：解析作品文档时用 `char-${角色名}` 生成人物标识，中文名不匹配宿主白名单 `^[A-Za-z0-9_-]{4,64}$`，生成设定图时被 `normalizeCharacterId` 拒绝。
- `shared/types/press.ts` 导出 `isPressCharacterId`，宿主校验与前端解析共用同一口径（删除 portraitService 里的重复正则）。
- `press/document.ts` 新增 `buildCharacterId`：ASCII 名称小写沿用，中文等字符转码点十六进制（如「林岚」→ `char-6797-5c9a`），同名稳定且合法；`- id：` 仅当本身合法才沿用，同名卡自动追加序号避免目录覆盖。
- 新增单测覆盖非法标识重生成、同名加序号、显式合法标识保留。

## 作品切换刷新与作品删除入口

- 切换作品不刷新：`WorkflowRouter` 新增显式作品选定 `selectProject` / `clearProject`，仪表盘与工作台的 `press/open` 打开作品后直接广播新的 `projectDir`，不再只靠 activeTextEditor 推导（webview 抢焦点时编辑器可能缺位）；工作台保留当前分区（如大纲）载入新作品内容。
- 删除作品：仪表盘作品详情页元信息下新增整宽「删除作品」按钮与二次确认弹窗，宿主新增 `press/deleteProject`（索引回查 → 拒绝含未保存修改的作品 → 整目录移入回收站 → 按前缀清理索引 → 清空路由事实中的当前作品）；前端删除成功经 sonner 提示并跳回作品列表。
- 新增 `PressProjectDeleteDialog.tsx`；`usePressProjectDetail` 增加 `deleteProject` 与 `isDeletingProject`。

## 角色卡改存作品目录

- 角色设定图落盘位置由全局 `press/_portraits/{characterId}/` 改为作品内 `press/{作品名}/_portraits/{characterId}/`，删除作品时随目录一并清理。
- `pressAi/generatePortrait`、`pressAi/listPortraits` 入参增加 `dirPath`（作品目录），宿主经 `readProjectSegments` 校验两段；插入/复制/删除的 `path` 由四段改为五段校验。
- 前端 `useCharacterPortrait(dirPath)` 及 `PressCharacterPage → CharacterEditDialog → CharacterDetail → CharacterPortraitPanel` 逐层传递作品目录，`WorkflowPress` 从 `press/workspace` 回包记录 `projectDir` 并下传。
- 旧的全局 `press/_portraits/` 不再读取，历史图片需手工迁移到对应作品的 `_portraits` 下。

## AI 对话按作品隔离

- `conversations` 新增 `project_dir` 列（schema v3），值为作品目录 `press/{作品名}`，NULL 表示通用对话；历史会话不回填。依赖该列的索引 `idx_conv_project` 必须建在补列之后，否则旧库建索引会因缺列失败。
- `chatRepository` 的 `getLatestConversation` / `listConversations` 增加作用域参数，用 `project_dir IS ?` 覆盖 NULL 比较；`AiChatService` 的 `getOrCreateSession` / `createSession` / `listSessions` 均接收作用域，并记录 `activeProjectDir` 供「添加到宅对话」等无作用域入口沿用。
- 协议 `ai/session`、`ai/newSession`、`ai/sessions` 接受可选 `projectDir`，宿主经 `toSafeSegments` 校验并限长 160，缺省即通用对话。
- 前端 `AiChat` 新增 `projectDir` 入参并透传给 `useAiChatSession` / `useAiChatHistory`；`WorkflowPress` 以当前作品目录传入并作为组件 `key`，切作品即重建对话页、换用该作品自己的会话历史。
- 新增 2 条仓储单测（历史列表只含同作用域、最近会话按作用域过滤）。
