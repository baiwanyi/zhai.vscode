**minor 落地 2（斜杠选中项跨会话残留）**：`SlashMenu` 常驻（`session` 为 null 时只 return null，组件不销毁），`selectedIndex` 是裸下标且只在列表变短时临时夹紧、从不归零。上次把选中项移到第 6 项、Esc 退出后重新输入 `/h`（4 项）→ `activeIndex = min(5,3) = 3`，默认高亮第 4 项，用户直接回车执行的是「分隔线」而非「一级标题」。改为「会话起点 + 相对下标」的派生结构：`session.range.from` 作会话标识（同会话内起点固定、只有 to 随查询词增长），起点变了 `selectedIndex` 自动回落 0，**不需要渲染期或 effect 里的 setState**（符合本文件「按边界取值、不额外同步」的既定风格）；方向键与 hover 改为 `setSelection({ start: sessionStart, index })`，方向键基于已夹紧的 `activeIndex` 计算（顺带修正了原先基于未夹紧旧值取模的巧合正确）。已知残留：删掉 `/xxx` 后在完全相同位置重新输入 `/` 会复用旧下标，概率极低。effect deps 需补 `sessionStart`（ESLint `exhaustive-deps` 会报两个 warning）。

**动因**：三个目录名与内容不符——`marks/` 里一个 ProseMirror Mark 都没有（全是 Decoration + NodeView + 资源前缀）；`toolbar/` 里塞着表情与斜杠两套完整功能外加命令层，而真正的工具条组件在 `layout/`；`selection/` 只有一个文件。改一个功能要横跨三个目录。
