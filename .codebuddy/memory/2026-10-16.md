## 悬浮提示箭头改为只画外侧两条边（根因查明：箭头外面有 span 包裹）

### 变更
- `src/components/ui/tooltip.tsx`：Arrow 的 `border border-border` 改为 `border-r border-b border-border`，只保留外侧两条边，使箭头描边与气泡描边连成一体，消除「独立小菱形」的观感；文件头维护提示补入真因。

### 根因（重要，解释此前两轮失败）
- 读 `node_modules/.pnpm/@radix-ui+react-popper@*/…/dist/index.mjs` 源码：`PopperArrow` 会额外渲染一层 `<span>`（源码注释原文：ResizeObserver 在 SVG 元素上量测尺寸不符预期），radix 在该层按 `placedSide` 施加 `rotate(-90deg / 90deg / 180deg)`；我们传入的 className 落在内层 `svg` 上。
- 于是 DOM 实为 `气泡元素 > span > svg`：调用处使用「直接子」选择器 `[&>svg]:…` **永远命中不到箭头**——这正是前两轮覆盖失效的真因。可用途径只有两条：不依赖结构的 CSS 变量继承（调用处局部反转 `--foreground`/`--background`，已验证有效），或直接改本文件的 Arrow 类。
- 方向结论：radix 的方位旋转与箭头自身 `rotate-45` 叠加后，四个方位下「外侧两条边」在 svg 自身坐标系中**恒为 `right` 与 `bottom`**，故单组类名即可覆盖全部方位，无需按 `data-side` 分支（且 `data-side` 也不在 svg 上，而在外层 span 的 transform 中体现）。
