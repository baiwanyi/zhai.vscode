## 修复激活失败：Cannot open database because the directory does not exist
- 运行时报错：扩展激活失败，`better-sqlite3` 打开 `index.db` 时父目录（globalStorage）尚不存在。
- 修复：`src/modules/common/db/connection.ts` 的 `openIndexDatabase` 在 `new Database(dbPath)` 前增加 `fs.mkdirSync(path.dirname(dbPath), { recursive: true })` 确保目录存在；同时按 import-x/order 修正 import 分组（builtin → external）。
- 验证：`pnpm exec tsc --noEmit` 与 `pnpm run compile` 均通过；重新加载扩展窗口后激活成功。

## 修复激活失败：未配置文档保存目录导致激活中断
- 运行时报错：未打开工作区且未配置 `zhai.storage.rootPath` 时，激活失败。
- 根因：`resolveStorageRoot()`（src/modules/common/config.ts）在无工作区且无配置时抛错；`IndexService.registerWatcher()` 在激活期同步调用它 → 直接中断激活；`selfCheck()` 同样会抛错（被 .catch 兜住但产生错误日志）。
- 修复：`src/modules/common/indexer/indexService.ts` 的 `registerWatcher` 与 `selfCheck` 对 `resolveStorageRoot()` 加 try/catch，无存储根时跳过监听注册与自检并记 info 日志，扩展可正常激活；待用户打开工作区或配置 `zhai.storage.rootPath` 后生效。
- 验证：`pnpm exec tsc --noEmit` 与 `pnpm run compile` 均通过。
