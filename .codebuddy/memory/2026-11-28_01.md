## 公众号目录代码重构

### 修改内容摘要
- 按「重构」规则对 `src/dashboard/wechat` 做结构分析，识别 6 个重构点，经用户确认后全部实施。
- 新增 `useWechatMutation`：收拢账号与批次 hooks 中 16 个写动作的置忙、请求、重拉、提示与收尾模板；取消类动作通过 `shouldReload` 谓词跳过重拉，失败重拉与阶段清空分别走 `onFailed` / `onSettled`。
- 新增 `coverCrop`：把取景框平移边界与 canvas 裁剪导出提取为不依赖 React 的纯函数，组件只保留 ref 读取与状态更新。
- 新增 `useRemountDialog`：统一「换 key 重挂载表单」的状态，列表页与账号弹窗 hook 各复用两个实例；返回对象用 useMemo 稳定引用。
- 拆分 `WechatIssueCard`：首篇主图与文章行菜单提取为独立 layout 组件，调序方向提升为 constants 共享类型；主文件从 354 行降到 226 行。
- 拆分 `utils.ts`：按账号、批次、文章、弹窗四个领域迁到 `utils/` 子目录，原 `utils.ts` 改为 re-export 门面，既有导入路径零改动。
- 新增 `useWechatStateEvent`：统一 wechat 通道广播的订阅、守卫判断与退订，鉴权失效与推送阶段订阅各改为一次调用。
