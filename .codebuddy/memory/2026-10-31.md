## 实现：公众号草稿提交（M3b）

- 渲染钩子：`render.ts` 增加 `resolveImageUrl`，改写发生在 mdast 的 image 节点上、渲染之前；渲染后不再动 HTML 字符串（属性值序列化时会转义，字符串比对会漏）。为此拆成 `parse → run → stringify` 三段，并补 `@types/mdast`。
- 素材：`connection.ts` 增 `wechat_materials` 表（唯一键 `(account_id, local_hash, type)`），新增 `db/materialRepository`（按 hash 查、写入）与 `materialService`（`locateWechatImage` 纯函数定位外链/本地/非法 + 读文件 + sha256 前 16 位 + 上传或复用）。只处理 jpg/png 且 ≤10MB；外链与 data URI 不上传；解析结果必须落在存储根内。
- 接口：`client.ts` 增 `uploadWechatImageMaterial`（multipart，字段名 `media`，60s 超时，素材错误码专属提示）与 `submitWechatDraft`（draft/add 与 draft/update，30s 超时，草稿错误码专属提示）。
- 服务：新增 `publishService.publishDraft`——逐篇渲染 → 补传图片（首张成功图片作封面）→ 无封面直接拒绝 → draft/add 或 update → 回写 `media_id` 与状态 `ready`；失败只回写错误、状态停在 draft。已推送的批次拒绝重新生成草稿。
- 接线：`issueRepository` 增 `updateWechatIssueDraft`；`WechatRoutes` 增 `wechat/issue/publishDraft`；`extension.ts` 让账号、素材、草稿共享同一份 SecretStore 与 TokenService（避免各自刷新互相失效），素材服务以函数惰性取存储根。
- 前端：`useWechatIssues` 增 `publishDraft`（180s 超时，成功 toast + 非阻断 warning 提示）；批次菜单「推送」改为「生成草稿 / 更新草稿」（无文章时禁用）；`ready` 状态文案改为「草稿已就绪」。
- 文档：`wechat.md` 同步素材表 DDL（去掉未实现的素材分组）、10.4 协议清单改为实际方法、技术选型与实现进度更新到 M3b。
