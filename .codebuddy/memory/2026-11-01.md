## 新增：打包与发布脚本（对齐 vscode-prompt-shortcut）

- `scripts/package.mjs`：vsce 打包输出到 `releases/<name>-<version>.vsix`，成功后 `code --install-extension --force` 覆盖安装本机；`--no-install` 跳过安装。约束：先 `mkdirSync` 再 `--out` 传完整文件名（否则 vsce 把 `releases/` 当文件名），重装必须 `--force`，`code` 不可用只提示不改退出码。
- `scripts/release-notes.mjs`：纯函数 `buildReleaseNotes(subjects)`，按 Conventional Commits 前缀分成「新功能 / 修复 / 性能 / 重构 / 文档 / 测试 / 构建 / 持续集成 / 其他」中文分组；过滤 `Merge` 与发布流水提交（`chore: 发布|更新版本清单`），无条目返回空串交由调用方回退自动生成。
- `scripts/release.mjs`：校验版本号 x.y.z、工作区干净（`--allow-dirty` 可跳过）、tag 存在时必须指向 HEAD、`gh` 已认证、Release 不存在 → `pnpm run package -- --no-install` → 用 notes 建附注标签（`git tag -a -F`）→ 推送分支与 tag → `gh release create` 带 vsix 与 `--notes-file`，临时文件在 `finally` 清理。期望主分支常量为 `VSCode`，偏离只警告不阻断。
- `scripts/publish.mjs`：校验版本号与 publisher、vsix 已存在、`vsce verify-pat` 通过后 `vsce publish --packagePath`，不重新打包。
- 命令：`package` = compile + `node scripts/bundle-native.mjs` + `node scripts/package.mjs`；新增 `release`、`market` 两条；`engines.vscode` 由 `^1.140.0` 提升到 `^1.144.0`（vsce 校验 `@types/vscode` 不得高于 engines，否则直接拒绝打包，与参考项目同口径）。
- 忽略：`.gitignore` 加 `releases/`，`.vscodeignore` 加 `releases/**`（脚本目录已被 `scripts/**` 忽略）。
- 验证（逐项）：`node --check` 对 7 个脚本全部 exit 0；`pnpm exec eslint scripts` exit 0；`pnpm run lint`（全仓）exit 0；`prettier --check scripts` 通过；`pnpm exec tsc --noEmit` exit 0；`pnpm exec node scripts/package.mjs --no-install` exit 0，产出 `releases/zhai-vscode-0.1.0.vsix`（67.4 MB）。`release` 与 `market` 依赖 `gh auth login` / `vsce login` 与真实发布权限，未联网执行。
